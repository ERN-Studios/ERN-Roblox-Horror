## Reproducerbar port og installeret efter-port

`run_client_local_contracts.py` ændrer hverken production, manifest eller Studio. Eksisterende testsource-readers får kun de gemte før/kandidat-inputs; deres production block extraction og assertions bevares. Compiler-candidates står separat i manifestet. Hvert artifact/proof-inputs SHA er registreret.

Efter root's installation køres:

Det gamle samlede manifest indeholder fortsat den ugyldige Loading-unit som immutable historik. Nedenstående all-unit port er derfor **ikke en aktuel efter-port** før root har afgrænset/reconciled Loading og dokumenteret ny native baseline; dens exact-hash guard må ikke omgås.

```powershell
$env:LUAU_BIN='C:/Users/mikke/AppData/Local/Temp/codex-luau-0.737/luau.exe'
$env:LUAU_COMPILE_BIN='C:/Users/mikke/AppData/Local/Temp/codex-luau-0.737/luau-compile.exe'
python artifacts/cleanup-20261009/run_client_local_contracts.py --verify-installed --portable-only
```

Denne mode kræver, at alle aktuelle canonical LF-hashes matcher de gemte sammensatte install-candidates; kontrollerer immutable individuelle og sammensatte før/efter-inputs; rerunner de samme gemte probes og actual compiler-porte; rechecker hashes efter test og gemmer en **separat** `client-locals-installed-gates.json`. Den overskriver ikke prepared baseline/negative-control receipts. En manglende eller ændret original/kandidat giver en hård fejl, ikke en stille ny baseline. `prepare_client_locals.py` er kun proposal-forberedelse og må ikke erstatte proof-inputs efter installation.

`--portable-only` bruger kun manifestets portable inputs og åbner aldrig `.git`-checkpoints. Standardmode prøver primær, portable og checkpointsti med exact hashes og virker derfor også når `.git` mangler. Proof-mappens lokale `.gitattributes` bruger `*.lua -text -whitespace`: original bytes bevares ved checkout, inklusive historisk whitespace, og diagnostikken undertrykkes uden at rette immutable evidens. Den separate readonly portability-port reproduceres med `python artifacts/cleanup-20261009/verify_client_local_portability.py`; resultatet gælder de historiske inputs. Kopi-/metadataforberedelsen er dokumenteret i `make_client_local_proofs_portable.py` og rører ikke produktionen.

Root's native efter-port omfatter frisk Source/editor/class/property/manifest-parity, Play full/TouchTarget og lobby loadingDone/health/console. Hvis Studio er i brugerens aktive Play, afventer writes Edit uden at stoppe brugerens test. Ved ny regression rollbackes kun den aktuelle scope fra dens exact native før-kilde. Ingen publicering er autoriseret her.
