# Codex visual observations

These observations are from the actual 420 px Roblox thumbnail files downloaded from the fresh live Studio catalog on 2026-10-01. They are not a substitute for the separate Claude review, and do not establish the live appearance of assets whose public thumbnail is a placeholder.

The token earners have legible center numerals at full size, but the surrounding gold gears, electric arcs, repeated crates, gradients and frames dominate at a 52–76 px shop size. The upgrade icons repeat the destination-tier image rather than communicate a transition: `TokenEarnerUp2to3` and `TokenEarner3x` have the same downloaded image hash; `TokenEarnerUp2to5`, `TokenEarnerUp3to5` and `TokenEarner5x` also share one hash. Six purchase IDs currently resolve to only three meaningful visual designs. A source → destination layout is needed for each upgrade.

The simple generated `TokenEarner2x.png` candidate has a clear ivory numeral/multiplication mark, an unambiguous silhouette, and one restrained teal token motif. It directly addresses the observed visual noise. Keep the token motif shared across earning tiers and immediate token packs so it denotes one currency. Keep purchase-pack counts 4/20 distinct from the earning label 2×/3×/5×. Color alone must not identify a tier or an upgrade.

Other utility icons need the following semantic corrections:

- Advanced Equipment: the current helmet dominates the picture, while the paid perk primarily grants a focused torch and stamina. A large recognizable flashlight beam is a more honest hero.
- Glowstick Customizer: three colored sticks already communicate the benefit; simplify the caps, remove the surrounding multicolor ring, and keep their silhouettes intact.
- Zyntra Supporter: the current elaborate medal can be reduced to one restrained supporter badge. It should not resemble another token earner or an unrelated combat rank.
- Entity Detector: the existing three-tier display is faithful. Keep LOW/MEDIUM/HIGH-style bars and a large scanner body; avoid radar dots or a shield which would imply precise enemy locations or guaranteed safety.
- Emergency Re-entry: the doorway plus returning arrow is recognizable. Simplify the bevels and retain that single action instead of using a generic resurrection halo.
- Expedition Pack: the repeated vials in the current picture do not correspond to the actual re-entry, shield and route-marker contents. One supply case with a clear, restrained symbol is preferable; any secondary contents should match the grant.
- 4 Research Tokens: the current four pieces are countable at full size but nearly lose their individual meaning when reduced. Add a large 4 plus the shared single-token motif.
- 20 Research Tokens: a stack communicates “many” without communicating exactly 20. Add a large 20 plus the same shared single-token motif.

The donation pictures consistently communicate support through a heart, but their decorative gold/cyan medal differences will disappear at small sizes. A single flat support symbol with readable tier/amount identification is appropriate for the Roblox purchase images. The current in-game donation list has no image fields; changing that layout is outside an icon-only replacement.

The real marketplace outfit pictures identify False Sun as a pale ivory hazmat suit with warm amber lenses and Static Wraith as a dark suit with purple/static accents. Keep their existing suit and mask silhouette. The two separately configured portrait assets currently download as Roblox generic missing-image placeholders, so do not infer the actual in-game portrait from those public responses. Existing paid UV texture IDs must remain unchanged.

Acceptance checks should include direct 52 px and 76 px viewing, correct source/destination on all three upgrades, no cropped glyphs or object silhouettes, clear separation of immediate currency packs from permanent multipliers, and visual correspondence to the actual perk. Actual Studio preload success and a screenshot of the rendered UI are required after installation; file inspection alone does not establish the game's rendering.
