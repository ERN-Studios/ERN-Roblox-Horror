# Authoritative Level 6 entity/decor verification

`tools/level6_build/import/verify_entity_decor_native_after.py` is a local, read-only verifier. It uses the completed native Studio captures in this task directory and the existing native assembly, place packing and Lune root extraction helpers. It never writes to Studio or stages Git files. Run it only after the final Edit-mode native-after capture has completed.

```sh
python3 tools/level6_build/import/verify_entity_decor_native_after.py --prepare-native \
  --acknowledged-concurrent artifacts/level6-entity-decor-20261001/verification/preserved-concurrent-studio-differences.json
```

If both captures are already assembled and packed, omit `--prepare-native`. The verifier expects 203 scripts before and 205 after. It checks the exact seven scoped Sources in `scoped-script-manifest.json`: five modifications and two new ModuleScripts, all under `ServerScriptService.Level 6 Systems`. Every Source must have editor parity and its expected before/after SHA-256. The verified seven-script mirror is exported **from native-after**, with exact Studio paths, classes, Source hashes, byte counts, asset URIs and editor parity in `verified-studio-mirror/manifest.json`.

The tool compares every unrelated script and each native top-level root, including all original Level 3 script and asset roots. Only the existing Level 6 Systems root is changed by this task. Concurrent changes are recorded and flagged for review rather than overwritten or silently accepted. A mismatch or Source/editor conflict blocks verification. A precise acknowledged-concurrent receipt can accept only the reviewed Source/root hashes and service property values, bound to the exact before/after raw native capture hashes; it cannot broadly ignore a level or accept future changes.
