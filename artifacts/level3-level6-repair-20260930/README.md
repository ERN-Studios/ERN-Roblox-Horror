The authoritative Studio edit place is `131311258779917` in universe `10559217407`. This repair was read from and applied to that live place at observed version `2421` on 2026-09-30. ZenMeister02 (`11374988579`) was the signed-in Studio tester. The repository is a downstream record, not an installation baseline.

The normal Level 3 loading failure reproduced in Studio Play. Five original Level 3 ModuleScript sources were restored from a *historical authoritative Studio native backup*, using guarded checks against the live `Source` and ScriptEditorService editor source. The Worn Party modules were left in place but are no longer called by the original Level 3. [The historical Level 3 installer](../../tools/level3_worn_party/README.md) is retired.

The Level 6 doorway and return prompt, transport, runtime access, crouch, and movement/noise scripts use the preview-specific check. The Level 6 visual adapter no longer assigns `CollisionFidelity` to a cloned mesh at runtime; the Blender bake already requests box collision when the mesh is created.
