# Level 6 Blender revision installed in authoritative Studio
The 2026-10-01 Blender revision is installed as the separate Level 6 developer preview in place `131311258779917`, universe `10559217407`. Studio reported a successful publication as **v2440**. [Publish receipt](publish-receipt.json) records the explicit result; existing servers were not restarted.

The reusable kit contains 61 Blender families, 279 material-split chunks and 74,092 unique triangles. The generated map retains 32 original Level 6 rooms and 37 graph connections and inserts three furnished 24×24-stud kitchen, staff and maintenance modules. Each has 14×10.5-stud portals; random seeds vary their placement and district routes. The map gains 1,728 square studs of floor. The 27 SHA-verified PNGs are group-owned and granted Use for this experience. Nine MaterialVariants supply carpet/wall, kitchen tile and diamondplate PBR; the props share a texture atlas.

[Verified Play results](qa/verified-play-summary.md) cover real E entry, five pickups and VCR insertion, escape and lobby cleanup, hiding, blackout/recovery, developer ESP, reader, a second seed and a bounded solo performance sample. Simulated drop placement is separately labeled. Multiplayer/mobile, a published-server mesh-bake smoke test and full entity traversal remain unverified.

[Native verification](native-after/revision-native-verification.json) confirms all eight scoped script Sources match their editor Sources and [repository mirrors](verified-studio-mirror/manifest.json), the 279 geometry payloads and 27 retained image payloads match their hashes, and the legacy source and all seven original Level 3 native subtrees are unchanged. The full native after backup is 65,918,701 bytes, under 100 MiB. Both native backups remain recoverable locally; Git includes reviewed summaries/hashes instead of the complete unrelated place data. Reconstructed .rbxl backups have 29 unsupported service-property assignments and 129 unreadable properties; original native root binaries and metadata are retained alongside them.

Studio remains authoritative. This package records the actual Studio result and is not permission to push repository scripts over a future live baseline. The empty owned `ServerStorage.Level6TextureImportReferences` folder from an unsuccessful insertion probe is preserved and separately reported; the retained raw RGBA source is not used by the final V2 rendering path. Failed V3 rendering is documented and not installed.

The derivative Blender source is [StudioImport_Portal14_Full_Seed101.blend](StudioImport_Portal14_Full_Seed101.blend). The original September 30 authoring files remain unchanged. See [import package](import-package/README.md) for regeneration and data format details.
