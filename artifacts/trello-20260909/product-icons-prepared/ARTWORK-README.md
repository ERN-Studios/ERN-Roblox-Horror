# Twelve proposed icon masters

All twelve configured offers now have separate, newly generated 1254 × 1254 PNG masters. The six Shop masters and the six donation masters each received an independent **9/10** artwork review; every individual icon scored at least 8.5. No regeneration was required. This is an artwork preparation package; it has not been uploaded or installed.

Exact generation prompts are in `art-prompts.json`. The full absolute generator originals and byte-exact workspace copies are recorded in `generation-origins.json` and `art-manifest.json`; the latter includes dimensions, mode, SHA-256, configured product/pass IDs and remaining export/upload status. Every original remains in place. `refresh_art_manifest.py` reads image metadata and hashes, verifies preservation, and builds the manifest plus `art-preview.html`. It does not modify image pixels.

The HTML offers full-master and CSS 76px/64px circular previews. It has not been opened or certified in a browser or Roblox during this artifact task. Master review therefore does not imply native small-size acceptance.
