# Independent native corner diagnosis

**The 10.5-range candidate fails this native corner case. It is not ready for publication.** The positive open and side-wall results remain useful controls; they do not override this failure.

I independently parsed all 449 samples in `native-seed188232071-corner.json` (SHA256 `80c527456de7e0d699633d075d8d69bb85bb644270eef400a045b85957b2983a`). The final observed waypoint, index 4 of 4, is `(656.813538, -1.120000, 899.963257)`. It lies **9.999994 studs** horizontally from the stationary tester. At the next observed ARRIVED state, the actual foot is `(656.483398, -1.120000, 898.654053)`, still **1.350188 studs** from that waypoint and **11.165026 studs** from the tester. The remaining **17.964676 seconds** retain this foot, Reached=true, HP100 and attack serial zero. The planned scripted dodge therefore never ran and is not counterplay evidence.

The production follower consumes each waypoint at the common 1.4-stud tolerance; `_reachedGoal` uses the same tolerance against its safe approach. This explains the observed early stop. The original ideal wall/corner geometry calculation did not bound the actual chosen approach plus the follower's stopping point tightly enough. It must not be cited as proof that 10.5 already covers every native corner.

The smallest supported candidate keeps attack range **10.5**, intermediate waypoint tolerance **1.4**, and all body/sweep checks, but introduces an optional **0.2** terminal-arrival tolerance used consistently for last-waypoint consumption and reached-state distance. Existing callers should default to their previous common tolerance; the separate stale-goal/installed-goal comparison should retain its existing contract. Conditional on safely reaching this recorded terminal point, the triangle bound is **10.199994**, below attack range. This is a geometric argument for the proposed targeted correction, not a completed native test or a guarantee for arbitrarily obstructed goals.

The last NextWaypoint is observed directly; private GoalApproach was not exported. Actual-source follower regression and a native corner retest must confirm continued safe motion and attack. A larger universal melee radius is not presently needed to explain or repair this particular failure. Native visual reach, counterplay and cleanup remain separate acceptance items. No production or Studio changes were made by this review.
