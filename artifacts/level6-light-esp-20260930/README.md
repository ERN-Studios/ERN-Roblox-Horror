# Level 6 ceiling lighting, night and CD developer ESP

The authoritative game is the live Roblox Studio place `131311258779917` in universe `10559217407`. This record describes a scoped Studio edit on 2026-09-30. The repository is a downstream mirror of the verified Studio state, not a deployment source. The original Level 3 was not edited for this task.

The first read-only [native snapshot](native-before/backup-metadata-summary.json) observed place version `2421`. Before writing, a second [native snapshot](native-prewrite/backup-metadata-summary.json) observed version `2424`. All 201 script paths, classes, and source hashes matched between those snapshots, as did the service properties and root inventory. Their native binary bytes differ and six existing Workspace roots appeared in a different order; the second snapshot was therefore used as the immediate write baseline. Every script's Studio `Source` matched its editor source in both captures.

Three Studio scripts were changed against that live baseline. The Level 6 World Builder places guaranteed working fluorescent ceiling fixtures in every actual room; large rooms receive four, and occasional dead fixtures remain only as dressing. The Level 6 Lighting Controller gives players in Level 6 a dark, `ClockTime=0.5` local night with black outdoor ambient and no environment fill, leaving the ceiling lamps to light the rooms; it restores the prior lighting after exit. RoundUI yields the lighting grade to that Level 6 controller. A new, enabled `StarterPlayer.StarterPlayerScripts.Level 6 CD Dev ESP` LocalScript adds cyan through-wall CD highlights for Level 6 preview-authorized players. The ESP follows CDs in world, carried, and dropped states, clears on collection or exit, and lets ZenMeister02 toggle the preview highlights with **B** without granting general developer cheats.

The [post-edit native snapshot](native-after/backup-metadata-summary.json) at observed version `2424` contains 202 scripts, all with matching `Source` and editor text and no skipped roots. [The four exact after sources](verified-studio-source/) were exported from Studio and match the reviewed candidates byte for byte. Of the original 201 scripts, 198 are unchanged; only the three named sources changed, and one LocalScript was added. The new script is `Enabled=true`, `RunContext=Legacy`, and `Archivable=true`. Top-level service properties/attributes, collision groups and matrix, material overrides, root names/classes and root count are unchanged; only `StarterPlayer.StarterPlayerScripts` gained one descendant. Complete `.rbxm` service-child snapshots, all source text, metadata and transfer parts remain local. The small [prewrite](native-prewrite/backup-file-hashes.json) and [after](native-after/backup-file-hashes.json) hash records are versioned. All 31 actual rooms had at least one bright ceiling fixture, and the generated world had 161 enabled `SurfaceLight` instances versus 127 in the pre-edit check. All five CDs had an ESP highlight. **B** toggled five highlights off and back on; collecting CD01 moved its highlight to the carried CD model. Returning to the lobby removed the world and highlights and restored `ClockTime=14`, `Brightness=1.35`; entering again regenerated 161 lights and five CD highlights. Startup `WaitForChild` warnings resolved once the preview remotes were created.
