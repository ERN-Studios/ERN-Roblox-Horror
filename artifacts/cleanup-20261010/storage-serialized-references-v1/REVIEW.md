Root is the sole native/HTTP owner. Artifact preparation, all local tests and
peer replays start no receiver and contact no Studio. The executable performs

Capture scope is one joint engine SerializeInstancesAsync forest: exact five old
forests / 1617 zero-script nodes, actual StarterPlayer and exactly 109 current
WeldConstraints. Constraints already under StarterPlayer are not duplicated as
input roots. Complete Archivable/identity/coverage/class/schema guards apply.
It requires actual reflected Instance-valued serialized Part0Internal/Part1Internal
(BasePart) and PlaceAvatarRules (Instance). Read failures remain recorded opaque
slots. Complete StarterPlayer/witness change and child/attribute watchers, all
213 Source/editor/class/property guards, exact original five native archive and
before/after serializer/transfer guards prevent promotion of changed captures.
Both complete game witness-discovery loops yield every 1000 nodes and immediately
run the unchanged A.checkpoint mode/owned-lease/previous-ledger/epoch checks. Full
Source/editor and five-forest exact serializer guards run at each phase boundary.
GetDescendants array acquisition and engine serialization themselves are atomic
engine calls; this package makes no timing or cancellation guarantee for them.

The raw joint buffer is bounded to 32 MiB and serialized twice byte-exact. It is
transferred unnormalized in 500000-byte parts. Independently attempted disconnects,
final and post-cleanup guards are mandatory; retained owned connections keep
their state reachable. Foreign replaced namespaces remain untouched.

`receiver.py` binds localhost only in Root's explicit --apply driver. It reuses
byte-pinned S19 strict JSON/count helpers, with a separate new Session/schema.
The capture ID is public; a fresh random 64-hex transfer token exists only in
memory and the exact private executed request. Private request/API/raw bytes go
to the new Root-selected private directory outside public artifacts. All output
files use exclusive creation. Headers, lengths, parts, order, duplicates and
completed claims are checked; raw failed messages/partials remain preserved.
The public template contains only `__ROOT_PRIVATE_TOKEN__`.

The driver makes one capture call with an explicit 600-second deadline. A valid
result/content-list means the native request completed, even on isError or bad
text, and the owned receiver is stopped. Transport exception or missing completion
envelope remains unknown: no retry or follow-up native calls, and the receiver
stays available for the outstanding readonly transfer/cleanup. Root must resolve
that request externally and write exact private `root-known-ended-release.json`
before this process releases HTTP. Local client close never claims cancellation.
Peer approval binds the exact template, driver and full frozen-pins digest.

`raw_binary_refs.py` reads the original binary header/INST/PRNT/PROP columns with
no reflection aliases or defaults. Every chunk and property payload retains its
raw offset/type/length/hash; other values remain opaque in the unchanged raw input.
It decodes actual Name strings and Ref referent columns; malformed, duplicate,
missing, unresolved, cyclic or unsupported required fields refuse. It requires
all five original target trees/class counts, all 109 constraints and one
StarterPlayer, and the three exact raw protected Ref column names/types. Public
Part0/Part1 aliases cannot substitute. Omitted/dropped fields never mean null.
The verdict records all 1617 target referent identities and five forest membership
lists, and all 219 owner/property/target mappings. Every raw null is explicitly
marked; every nonnull Ref remains resolved by identity and native class.
LZ4 and uncompressed chunks are supported; Zstd preserves raw but remains pending.
