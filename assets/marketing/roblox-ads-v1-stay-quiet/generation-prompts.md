# Generation prompt record

All creatives use the built-in ImageGen workflow. Input images are references for character, creature, environment, composition quality, and lighting only; no source image is treated as a collage component unless stated.

## Shared prompt base

```text
Use case: ads-marketing
Asset type: 16:9 landscape Home-feed creative for the Roblox horror game "BACKROOMS: STAY QUIET [CO-OP HORROR]"
Primary request: Create one polished cinematic third-person Roblox horror gameplay moment with a single clear focal event that is readable at thumbnail size.
Subject: Preserve the same small blocky tan/yellow hazmat protagonist with a ribbed black backpack. Use the approved creature design appropriate to the selected level.
Style/medium: Clearly Roblox game imagery, not live action; blocky game proportions with realistic PBR materials and cinematic practical lighting.
Composition/framing: Exact 16:9 landscape feel, strong foreground/midground separation, clear silhouettes, controlled negative space.
Lighting/mood: Tense, dark, and atmospheric with one strong colored threat or navigation accent and a subtle vignette.
Constraints: Bloodless creature horror; no gore; no title, text, logo, HUD, fake UI, or watermark; no extra limbs; no unrelated characters; no misleading gameplay elements.
```
