## Canon locks applied

- Every Level 1 scene depicts detection, alert, or pursuit. The giant hazmat Entity therefore has exactly two vivid red hunt-state eyes in all ten images—never amber/yellow, never extra eyes, and never a mouth.
- Friendly players use the current mustard/olive suit, blank black visor, black gloves/boots, and ribbed black backpack.
- Level 2 uses the live faceless Pool Foam mesh identity: tangled, saturated primary-color foam noodles with a narrow cone-like top. The pale-aqua proxy, retired Slidemouth, and missing Pool Slide humanoid are excluded.
- Level 3 uses the current faceless red-headed Mall Manager in its worn orange-and-cream manager shirt. It appears only in valid hunt/finale scenes; the first-disc and five-second-warning scenes correctly omit it.
- The under-table scene is first-person and does not render a supposedly hidden player body.
