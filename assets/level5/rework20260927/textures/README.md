# Candidate facade texture

`clapboard-cream-v1.png` was made with ChatGPT's built-in image gen tool on 2026-09-27 for the pale cream horizontal siding visible across the supplied Level 5 references. The generation requested an orthographic, square, repeating albedo texture without windows, trim, perspective or directional lighting. A second image gen edit reduced heavy paint wear and requested continuous tile edges; the selected second output is stored here. No Claude image generation or outside stock texture was used.

This is a **candidate** project asset. It has not been uploaded to Roblox, assigned to a MaterialVariant or evaluated for scale, tile seams or appearance on the matched reference cameras in Studio. Do not treat it as an approved 1:1 material until those checks pass.
