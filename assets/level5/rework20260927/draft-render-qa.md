# Isolated draft render QA — 2026-09-27

These are **temporary Studio Edit renders of the uninstalled reference builders**, not views of the current playable Level 5. The renders used the source snapshot in local commit `954486e`; later working-tree revisions to the draft modules are not assessed by these pictures. The captures used an Architecture-compatible test kit, a distant Workspace origin, and each builder's suggested camera. That kit reproduces the builders' parts and basic window/floor helpers, but it does not reproduce all live MaterialService variants or round Lighting. Compare form and composition first; colour and exposure require a matched in-game pass. The ten original screenshots are visible in the conversation but not available as pixel files here, so this is qualitative visual QA rather than a measured overlay.
