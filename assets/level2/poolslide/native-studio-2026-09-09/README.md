# Native Studio entity-template snapshot — 2026-09-09

This is an **asset-only native Roblox model backup**, not a whole-place backup
and not a deployment instruction. It preserves the Studio-authored
`ServerStorage.Level2Assets.Level 2 Pool Slide Template` from the captured
place `131311258779917`, universe `10559217407`, Edit version `1793`.

`level2-pool-slide-template.rbxm` is a mechanical hex decoding of the existing
authoritative `current-review/template-native-before.json` snapshot. The decoder
checks every hex pair, the expected **76,255 bytes**, the expected unsigned
**Djb2 hash 92,721,504**, and the native Roblox binary header before writing.
SHA-256 hashes and provenance are recorded in `manifest.json`.

No model was imported, no Studio instance was replaced, and no asset was
uploaded or published during this preservation step. Existing external Roblox
mesh/animation asset dependencies still require the original asset access.
The binary has not been round-trip imported or play-tested by this archival
operation; byte validation is not proof of gameplay, rendering, or rig behavior.

Do not restore this model over a newer Studio model. Studio remains the source
of truth; inspect the fresh model and preserve concurrent developer changes.
Obtain a separate full native place backup for the complete game, geometry,
scripts, settings, and other instances. This single-template file does not
provide that coverage.
