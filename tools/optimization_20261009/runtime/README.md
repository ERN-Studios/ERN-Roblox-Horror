# Actual runtime Stats sampler

Root executes `measure.luau` directly in the active Client or Server Play DataModel after installation. It returns JSON and does not create fixtures, modify source/properties, call gameplay controls, or start/stop Play. The script rejects Edit and an unexpected place/universe.

The Stats window lasts three seconds, with readings spaced about 0.05 seconds. Median/p95 describe these spaced native observations, including any engine averaging in the property; they are not an exhaustive distribution of every rendered frame. The return from `task.wait` is discarded. Native Stats supplies CPU/render/physics/scheduler values. The script produces no FPS claim, and server renderer fields are context-inapplicable.

Stats total memory and per-tag memory are sampled about twice per second. Failed, missing, nonnumeric, or nonfinite fields retain an unavailable reason and omit numeric summaries. A native zero remains an observed zero with a caution about its meaning. Tag memory is skipped when tracking is disabled; the API's disabled-tracking zero is not memory evidence. [Official Stats documentation](https://create.roblox.com/docs/reference/engine/classes/Stats), [official detailed API source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/Stats.yaml).

FrameTime and HeartbeatTime use documented seconds. Other time-property units remain explicitly raw where the current documentation does not specify them. Network properties use documented kilobytes/second despite the `Kbps` spelling; memory methods use megabytes. Total memory is OS-reported and differs from summing category values. [Official detailed Stats API source](https://raw.githubusercontent.com/Roblox/creator-docs/main/content/en-us/reference/engine/classes/Stats.yaml).

The output records scene context before/after, current character/camera positions, an actual-world floor ray, current local PlayerGui loading covers, replicated Imports absence and budget-script presence. An end snapshot counts received L2/L4/L5/L6 roots and marked Wanted/Enabled lights/emitters, and lists other workspace world candidates. L2 recognizes the actual runtime name `Level 2 Generated World` and the parked `Level2PoolroomsMap` alias. Its own census duration is separate from the Stats window. This is a current-scene smoke measurement, without a matched before/after baseline or gameplay-performance conclusion.

Offline validation used official Luau 0.741: `measure.luau` compiled; `test_measure.py --luau <luau.exe>` passed five scenarios for Client/Server scope, median/p95 aggregation, disabled memory tracking, inaccessible/nonfinite metrics, unavailable GUI/owner evidence, and Play interruption. These service stand-ins are not a native Stats measurement. The effects agent did not execute the script in Studio; root owns actual execution and receipts.
