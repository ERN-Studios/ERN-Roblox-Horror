## Reusing the checks

`tools/tests/level5_geometry_runtime_qa.luau` is a read-only server inspection for an already-built Level 5 Studio Play world. Execute its body in an actual temporary server Script during Play and capture its returned table. A command-tool require can have a separate module cache with an empty adapter manifest; that is not evidence that the runtime map is absent. Remove the temporary harness or stop Play after inspection. It does not build the map, move players or mutate instances. Its collision candidates require review and actual traversal; it is not an exhaustive navigation proof. The existing `level5_furnishing_runtime_qa.luau` checks furniture, windows and mold backing.

The observer-staging fixture contains the exact final `protectArrival` function. From the repository root, with the Luau CLI on PATH (or `LUAU` set to its executable), run this source-equality guard before its six behavior assertions:

```sh
python3 - <<'PY'
from pathlib import Path
import os, subprocess
adapter = Path("ServerScriptService/Level 5 Systems/Level 5 Round Adapter.ModuleScript.lua").read_text()
test = Path("tools/tests/test_level5_observer_staging.luau")
fixture = test.read_text()
start = "local function protectArrival(spawnFrame: CFrame)"
actual = adapter.split(start, 1)[1].split("\nfunction Adapter.GetManifest()", 1)[0].strip()
embedded = fixture.split(start, 1)[1].split("\n protectArrival(frame)", 1)[0].strip()
assert actual == embedded, "Refresh fixture from the authoritative adapter before testing"
subprocess.run([os.environ.get("LUAU", "luau"), str(test)], check=True)
PY
```

The existing access test runs against repository-relative sources with `python3 tools/tests/test_level5_access.py --sources . --luau /path/to/luau`. It tests authority/transport decisions, not live teleportation.
