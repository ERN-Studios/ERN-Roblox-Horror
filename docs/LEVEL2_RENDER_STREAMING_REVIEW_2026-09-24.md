# Level 2 render distance and nearby loading — 24 September 2026

Status: investigation only. No streaming property, LOD, geometry, or publication was changed for this review. [Trello Zpj0Gkbb](https://trello.com/c/Zpj0Gkbb) remains in Testing. Roblox Player playtesting was skipped at the owner's request.

## What is running

- The [published v2081 binary receipt](../artifacts/publish-v2081-20260924/README.md) identifies the place and source snapshot. A read-only decode of that exact binary (SHA-256 `86f1a680f256d7a47ab26b320cd0b490613ee5452430704689b9f6e99a809cfa`) found `Workspace.StreamingEnabled=true`, `StreamingMinRadius=64`, `StreamingTargetRadius=1024`, `StreamOutBehavior=Opportunistic`, `StreamingIntegrityMode=PauseOutsideLoadedArea`, and `ModelStreamingBehavior=Default`. The local native v2074 backup has the same values. These non-scriptable Workspace settings cannot be read through Studio MCP Luau; the binary audit is evidence for the published version, not for a later unpublished property edit.
- Level 2 spans a 1,400-stud square (`Level 2 Configuration.ComplexExtent`). A 1,024-stud target circle centered on the map reaches its corners (~990 studs); this is a geometric inference, not a measurement of how much a particular device actually receives. The engine can retain or adapt streamed content according to device conditions. The configured minimum/target radii are Roblox's documented defaults, and opportunistic stream-out and pause outside loaded area are already enabled.
- The hidden tile-face culling switch and both uploaded arch meshes are active. The measured seed `1182081016` changed from 71,771 to 56,001 Level 2 descendants and from 42,051 to 29,103 Texture instances. An active Pool Slide round and PC 60 FPS were reported on the [render card](https://trello.com/c/Zpj0Gkbb). Physical phone/tablet FPS, memory, receive/load time, and pop-in have not been measured.
- The two arch MeshParts use `RenderFidelity=Precise`, but each is only 108 vertices / 212 triangles; 166 ribs total about 35,000 triangles. Changing their mesh LOD alone is unlikely to address the larger instance/Texture count. Level 2's decorative portal spandrels and face rings are the stronger structural pilot: historical counts attribute about 7,936 Parts and 15,872 Textures to them. Confirm current counts by name in a generated world before claiming that entire saving.
- The runtime world is a single large top-level Model; halls have child Models, while much corridor geometry is grouped in Folders. The Level 2 builder sets no `Model.LevelOfDetail`. Roblox recommends SLIM for spatially small static Models, around 64 studs or less, rather than applying it to one huge container. The current 1,400-stud generated world is therefore not a safe one-line SLIM target. LOD composites also do not provide gameplay collision or raycasts.
- The prior Pool Foam server problem was navigation, not rendering: five active Foams improved from 11.6 to 54–56 server Hz after 96-stud route planning. A client render-distance change cannot be counted as that server fix.

## Controlled next experiment

1. Capture a **physical phone and tablet baseline** in the same published Level 2 seed/route, including arrival, a quiet hall, second-pump spawn, third-pump chase, and round exit. Record client FPS or p50/p95 frame time, memory, render draw calls, streamed instance count/receive spikes, visible pop-in and loading pauses; record server heartbeat separately. Keep graphics quality, player count and route fixed. This is also the remaining gate on [physical QA lUKD3R8G](https://trello.com/c/lUKD3R8G).
2. If instance/Texture replication or draw calls dominate, have Claude build a **flagged portal-spandrel mesh A/B** using Codex-provided reusable mesh assets. Keep the existing invisible collision, objective paths, Pool Slide/Foam navigation and tile appearance; measure counts and visual seams with the same seed before enabling. Do not replace the current arches just to test LOD on their small meshes.
3. Only if baseline and mesh A/B still show a streaming burden, test `StreamingTargetRadius=768` (then 512 if needed) and `ModelStreamingBehavior=Improved` in an isolated native copy, one variable at a time. Retain `StreamingMinRadius=64`, `Opportunistic` stream-out and `PauseOutsideLoadedArea`. Check full traversal, doors/objectives, entities, sound, Level 2→3 transition, re-entry and multiple clients at stream boundaries before publication. Do not infer a benefit from a lower instance count alone.
4. Consider per-section SLIM models only if distant architectural continuity is actually needed after a smaller target radius. That requires small static spatial groups and a measured visual/streaming comparison; the whole generated world is too large, and animated/dynamic models are not candidates.
