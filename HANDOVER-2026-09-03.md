## What shipped on 2026-09-03

Five verified defects, each applied in Studio first and mirrored back:

- **Round start could wedge the whole party** (`GameManager`). `CharacterAutoLoads` is off,
  so a player whose `LoadCharacterAsync` threw had no character and
  `player.CharacterAdded:Wait()` never fired. The round-start loops are serial, so one bad
  load parked the thread: `playRound` never ran, `roundBusy` never cleared, everyone else
  sat behind the loading cover. Levels 1 and 3 have no client-side backstop. Replaced by
  one `spawnGameplayCharacter` helper used at all four sites, which retries and gives up
  only once the player has left.
- **A failed `IsFriendsWith` was cached as a denial** (`GameManager:896`), locking a real
  friend out for the rest of the countdown. Only definitive answers are cached now.
- **`% MAX_SEED` aliased the top of the seed range** — `Level2Seed = 2147483647` built seed
  0's map. Both adapters now reject out-of-range instead of wrapping.
- **Four unbounded `WaitForChild` calls in the Mall Manager** ran inside the adapter's
  `pcall`, so a missing ServerStorage asset meant the pcall never returned and the hunt
  silently never spawned. One `requireAsset` helper with a 10 s bound.
- **The Master Tuning panel took `K`**, which ZyntraStore's dev cards and UIRegression both
  advertise as the Level 3 blackout skip — and it sank the input. Moved to `F4`; no
  function key is bound anywhere else in the place.

## Traps that have already cost time here

- **Apply changes in Studio first**, through `ScriptEditorService:UpdateSourceAsync`. A raw
  `.Source` write leaves LocalScripts running stale bytecode, and it refuses any string of
  200,000 characters or more. Read back through `.Source`, never `script_read`, which can
  serve a stale editor buffer. When Studio is closed, edit the repo and run
  `python tools/record_pending_push.py` — then **do not pull** until the push lands, or
  Studio's older copy overwrites your edit.
- **`pull_source_from_studio.py` does not update the manifest's `counts` block.** It was
  wrong three times on 2026-09-03 alone. Fix it by hand and let
  `tools/tests/test_full_sync_contract.py` confirm.
- **Never copy a script count into prose.** It has been wrong in `README.md` and `CLAUDE.md`
  four times. The manifest's `counts` field is the only place it is true.
- **The knowledge graph under-covers `GameManager`** — 4 symbols out of 2,640 lines — plus
  the Level 3 Test Suite, the Mall Manager AI Controller and the Level 3 Lighting
  Controller. An empty graph result for those files is not evidence of absence. Grep them.
- **The `ruflo-core` plugin's hooks damage this repo.** On 2026-09-02 they truncated 32
  files in `tools/` and corrupted `studio-sync-manifest.json` in a single operation, and
  they litter the repo root with files named after line numbers. Everything was recovered
  from git. If you see stray numeric filenames appear, that is what it is.
- **Look Level 1's scripts up recursively.** `ServerScriptService:FindFirstChild(name)`
  returns nil from inside a folder and every call site fails silently on nil. Pass `true`.
