## Traps that have already cost time here

- **Apply changes in Studio first**, through `ScriptEditorService:UpdateSourceAsync`. A raw
  `.Source` write leaves LocalScripts running stale bytecode, and it refuses any string of
  200,000 characters or more. Read back through `.Source`, never `script_read`, which can
  serve a stale editor buffer. When Studio is closed, edit the repo and run
  `python tools/record_pending_push.py` — then **do not pull** until the push lands, or
  Studio's older copy overwrites your edit.
- **New scripts cannot be pushed.** `push_repo_to_studio.py` aborts on a script Studio
  does not hold. Create it in Studio first (`Instance.new` plus `UpdateSourceAsync` through
  `execute_luau`), add the manifest item by hand with `sha256_of` / `canonical_bytes`
  from `tools/studio_source_contract.py` (NOT a raw-bytes hash), then let the drift audit
  confirm it matches.
- **`require` from `execute_luau` is a separate module instance**, even in a play
  session's Server datamodel: `Level 2 Pool Foam Controller.GetDebugSnapshot()` returned
  `Running = false` while the game's own copy was running five entities. Read
  attributes and instances instead of module state.
- **`pull_source_from_studio.py` does not update the manifest's `counts` block**, but the
  push tool does. Either way, `tools/tests/test_full_sync_contract.py` is the check.
- **Never copy a script count into prose.** The manifest's `counts` field is the only
  place it is true.
- **The knowledge graph under-covers `GameManager`** — 4 symbols out of 2,640 lines — plus
  the Level 3 Test Suite, the Mall Manager AI Controller and the Level 3 Lighting
  Controller. An empty graph result for those files is not evidence of absence. Grep them.
- **Subagent shells drop stray files in the repo root.** A `975` (grep output) and a
  duplicate `MEMORY.md` appeared during the audit batch. `git status` before committing.
- **Look Level 1's scripts up recursively.** `ServerScriptService:FindFirstChild(name)`
  returns nil from inside a folder and every call site fails silently on nil. Pass `true`.
